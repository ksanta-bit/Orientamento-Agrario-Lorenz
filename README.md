# Istituto Agrario K. Lorenz — Il futuro si coltiva

Presentazione web di orientamento per gli studenti delle scuole medie.

IIS 8 Marzo – K. Lorenz, Mirano · anno scolastico 2026–2027.

Autore: prof. Gianluca Simonetti. Dirigente scolastica: dott.ssa Roberta Gasparini.

## Utilizzo

Aprire la pagina GitHub Pages. Usare le frecce per avanzare e il comando «Proiezione / schermo intero» per presentare. Il pulsante «Indice» consente di scegliere una schermata. Tutti i filmati sono senza audio e possono essere messi in pausa.

La versione pubblicata conserva contenuti, fotografie, animazioni e comandi della presentazione approvata. Le immagini e i video sono serviti come file separati, per evitare di scaricare un unico HTML molto pesante.

I riferimenti alle fonti e le precisazioni sull’origine delle immagini e dei filmati sono nelle note della presentazione. Le informazioni sull’offerta formativa e sulla riforma vanno verificate prima di riutilizzare il materiale in anni successivi.
